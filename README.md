# 🚀 MVP Web3 Project

## 📌 Overview
This is a Web3 MVP project where users can connect their wallet and interact with blockchain features.

## ⚙️ Tech Stack
- React.js
- Node.js
- Ethers.js
- MetaMask

## 🔗 Features
- Wallet connection
- UI dashboard
- Blockchain interaction

## ▶️ How to Run
git clone <repo-link>
cd project
npm install
npm run dev
